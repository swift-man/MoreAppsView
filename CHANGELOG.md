# Changelog

## [0.1.0] - 2026-08-01

- Added the public `MoreAppsKit` Swift package for iOS 26.0 and tvOS 26.0.
- Added TCA-driven catalog state, filtering, event delivery, and deep-link fallback.
- Added static and Alamofire-backed remote JSON providers.
- Added cached and coalesced Alamofire image loading.
- Added UIKit and SwiftUI entry points with Dynamic Type, VoiceOver, and tvOS focus support.
- Added Swift Testing coverage and iOS/tvOS integration samples.
